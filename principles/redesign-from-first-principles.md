# Redesign from First Principles

- **Parent:** `design` ([PRINCIPLES.md](../PRINCIPLES.md))
- **When:** integrating a new requirement into an existing design.

Do not bolt the change on. Redesign as if the requirement had been there from day one.

- Read every affected file and understand the current design.
- Ask: "if we wrote this from scratch with this requirement, what would we build?"
- Carry the change through every reference: types, docs, examples, the rationale.
- Think through the whole redesign, then deliver it in increments.
